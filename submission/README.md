# YDSE submission files (private generated outputs)

- `YDSE.csv`: final locally validated candidate.
- `YDSE_reproduced.csv`: independent regeneration, same bytes.
- `YDSE.md`: technical report, accepted Markdown alternative to PDF.
- `fallback/baseline_smooth50.csv`: independently regenerated official baseline.

Generated CSVs are intentionally ignored by Git. Upload the selected CSV directly
to the organiser's form only after the team reviews the release. Publish the
source repository separately. Do not upload both predictions as competing entries:
the form accepts one editable team response, and the last timely response is scored.

The public-ready technical report also lives in `docs/technical_report.md`.
The team must verify signed terms, registration name YDSE, eligibility, submission
URL and exact cutoff time. No upload/publication has been performed by the agent.
